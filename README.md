# onpage-claude

## 피드백 포인트

자사 웹 서비스 위에 위젯으로 설치해 쓰는 사내 피드백 & QA 협업 플랫폼 프로토타입이에요.
Toss Design System(DESIGN.md + tokens.json)을 기반으로 만들었어요.

- 라이브 버전: https://claude.ai/artifact/PhZyCv2ujpB1UwrpFxQedm (조직 내부 공유)
- 소스: `index.html` 한 파일 (빌드 없음)

### 실행

```bash
open index.html
```

브라우저로 바로 열면 데이터는 이 브라우저의 localStorage에 저장되고, 같은 브라우저의 다른 탭과 동기화돼요.
claude.ai 아티팩트로 열면 공유 DB로 모든 구성원에게 실시간 반영돼요.

### 화면 구성

- **호스트 데모**: 위젯이 설치되는 가상 서비스 화면 3종(홈·콘텐츠·설정)
- **플로팅 위젯**: 우측 하단 버튼 → 우측 패널
  - 기능정의·QA: 상태 칩 필터, 검색, 목록, 상세(캡쳐·마커·번호 칩으로 해당 페이지 이동, 상태·담당자·우선순위, 댓글·답글, 메모 연결), 등록
  - 메모: 날짜별 그룹, 답글, 상태, QA로 등록
  - 화면 위치 지정: 포인트 / 영역(1개), 상대 좌표 + 대상 요소로 저장, 등록 시 화면 캡쳐
- **관리자 대시보드** (`#admin`): 상태별 통계, 담당자·고객사·우선순위 현황, 전체 피드백 테이블과 필터, 고객사별·담당자별, 메모

### 디자인 시스템 메모

- tokens.json의 OKLCH 값은 화면 캡쳐 엔진(html2canvas)이 읽을 수 있도록 sRGB hex로 변환했어요.
- 컴포넌트는 역할 토큰(`--fb-*`) 한 층만 참조해요.
- 우선순위 뱃지는 배경형, 진행 상태 뱃지는 텍스트형으로 분리했고 Dot은 쓰지 않아요.
